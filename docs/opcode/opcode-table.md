## 2. 变量引用操作数(**Confirmed**)

```
[op: 0x48|0x56|0x76][operand_len: u16 = 3][prefix: u8][id: u16 LE]
```

| 前缀字节 | 字符 | 含义(手册 §变量/§标签) | 语料次数 |
|---|---|---|---|
| 0x40 | `@` | 数值变量(INT/FLT 64 位) | 67,030 |
| 0x24 | `$` | 字符串变量 | 18,708 |
| 0x23 | `#` | 标签/宏引用(`GO[#=es.ERIS]`) | 5 |
| 0x60 | `` ` `` | (手册未述,罕见) | 5 |

- 0x48 = 取值;0x56 = 引用(赋值目标);0x76 = 下标/成员形式(fixup 改写)
- YSCM 的 `G_*/S_*/F_*` 变量声明命令与"全局/本地"分类对应手册;id 编码细节待引擎侧确认

## 3. 字符串操作数(0x4d,**Confirmed**)

载荷 = `"` + SJIS 文本 + `"`(编译器类型 4 自动加引号)。
内容三类:标签/宏名(`es.BT.CG.SET` 等,= 源码 `#=es.BT.CG.SET` 的跳转目标)、
资源路径(`sysse/sse02`)、UI 文案(`"Quit"`、`"全部登録します。よろしいですか？"`).

## 5. Slot tag 模型(更新)

tag = u32;`tag >> 16` 分布实测:{0x0000:19,687, 0x0001:96,228, 0x0002:3,115,
0x0003:73,140, 0x0004:1, 0x0101:1,705, 0x0102:50, 0x0103:136, 0x0201:195,
0x0202:14, 0x0301:81, 0x0302:148, 0x0401:40, 0x0501:15, 0x0601:2, 0x0701:43}。

已证伪:「tag 低字节 = YSCM 命令下标」。结合 SDK 源码的新理解:group 3 的 M-串
多为 `es.*` **标签名**(ERIS 系统脚本的跳转目标),tag 低 16 位疑似编译期分配的
实例/参数编号 —— 语义仍 Unknown,待引擎侧 tag 处理代码确认。

## 6. 密钥(跨文档互证,**Confirmed**)

**key = CRC32(种子串) 的大端 4 字节**(标准 IEEE CRC32,查表驱动)。
- 默认种子 `"Yu-ris"` → CRC32 = 0xd36fac96 → 字节 `d3 6f ac 96`
  =《SDK编译器调用》的默认密钥 `0x96AC6FD3`(LE u32 读法)✓
- 样本游戏 `2b904f93` → 种子被改(商业版);引擎内含同一 CRC32 表
  (kemonomichi2.exe 文件偏移 0x192c80),种子串待引擎侧定位
- XOR 相位:编译器**每区独立** `key[i&3]`;与"绝对相位"模型在
  `part1_len ≡ 0 (mod 4)`(302/302 成立)时等价
